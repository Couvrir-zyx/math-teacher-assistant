# 数学教师助手 - MathTeacher Assistant

一个专为高中数学教师设计的图片识别与话术生成工具，帮助老师快速生成微信群课堂总结话术。

## 功能特点

### 🖼️ 图片上传与识别
- 支持拖放上传图片
- 自动识别图片中的文字内容（OCR技术）
- 支持常见图片格式：JPG、PNG、GIF、BMP

### 📝 智能话术生成
- **3种预设模板**：
  1. 新课讲解模板
  2. 习题讲解模板  
  3. 复习总结模板
- **自定义模板**：可保存自己的话术模板
- **智能填充**：根据识别内容自动填充模板变量

### ✏️ 便捷编辑功能
- 可视化话术编辑器
- 一键复制到剪贴板
- 历史记录保存（最近10条）
- 支持快捷键操作

## 使用流程

1. **上传图片**：点击"选择图片"或拖放图片到上传区域
2. **自动识别**：系统自动识别图片中的文字内容
3. **选择模板**：根据课堂类型选择合适的模板
4. **编辑话术**：微调自动生成的内容
5. **复制分享**：一键复制到剪贴板，粘贴到微信群

## 模板变量说明

模板中使用 `{变量名}` 格式的占位符，系统会自动填充：

### 常用变量
- `{日期}`：当前日期
- `{知识点1}`、`{知识点2}`：从图片中提取的数学知识点
- `{重要公式}`：识别到的数学公式
- `{方法技巧}`：解题方法
- `{学生名单}`：学生姓名（可手动修改）
- `{掌握程度}`：学生掌握情况
- `{薄弱环节}`：需要加强的内容
- `{作业内容}`：课后作业建议

## 技术特点

### 纯前端应用
- 无需服务器，直接在浏览器中运行
- 使用HTML/CSS/JavaScript开发
- 数据保存在本地浏览器中

### OCR识别
- 使用Tesseract.js进行文字识别
- 支持中文和英文识别
- 自动处理图片预处理

### 响应式设计
- 适配电脑和手机浏览器
- 简洁直观的用户界面

## 自定义配置

### 修改模板
1. 在编辑器中修改话术内容
2. 点击"保存模板"按钮
3. 下次使用时选择"自定义模板"

### 添加新模板
在 `app.js` 文件的 `templates` 对象中添加新的模板：

```javascript
const templates = {
    // ...现有模板...
    'my-new-template': `你的模板内容
    使用{变量}格式`
};
```

## 注意事项

1. **图片质量**：清晰的图片识别效果更好
2. **文字方向**：建议使用横向文字图片
3. **隐私保护**：所有处理在本地完成，图片不上传服务器
4. **网络要求**：首次加载需要下载OCR引擎（约5MB）

## 快捷键

- `Ctrl + Enter`：智能生成话术
- `Ctrl + C`：复制当前话术（不在编辑框中时）
